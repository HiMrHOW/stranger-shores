# 陌岸 · Stranger Shores

独立于 blind-spot-game 的原创像素叙事试玩。居民使用由概念、交际意图与现场指认组成的虚构符号语言，不是逐汉字替换。你通过观察、取水、搬木料与协商，和他们一起修好船。

## 游玩

在 iPad Safari 或桌面浏览器打开网页即可。点地面行走；点人物/物件自动走近。左下区域按住后拖动：轻推慢走、远推快走、松手停止，摇杆以手指落点为中心。右下按钮根据附近人物和行走状态显示交谈、查看或停下。面板可从顶部把手向下拖动收起。“旅途 / 去哪里”提供地点导航。键盘支持 WASD / 方向键、E / 空格、J。

横竖屏均适配，声音默认关闭且只在用户点击后启用。进度与手记仅存本机 localStorage，无登录、遥测或外部服务；浏览器禁止存储时仍可在本次页面中玩完。不能保证跨设备同步。

这是单人短篇原型，包含一个岛、五个交互地点、八条见闻记录、可编辑猜想、两条取水途径、三种刻印结果及离岛结尾。没有联网双人模式。中文是动作观察和操作提示，不是 NPC 话语译文。

## 文件与开发

`index.html` 是完整可运行且包含全部图像的单文件源码。可直接托管在 GitHub Pages，无安装步骤。

模块化源文件另附 `source.zip`：`src/core.mjs` 语义与状态、`src/world.mjs` 瓦片关卡/碰撞/寻路、`src/game.js` 游戏循环与输入、`src/style.css` 布局。修改后在源目录运行 `node build.mjs`，用 `node tests.mjs` 检查。生成文件在 `dist/index.html`。

## v0.2 · 观察动作

水井互动新增三阶段像素动作回放：提水、添共用水槽、装自己的壶。支持暂停、下一步与重看；系统开启减少动态效果时默认暂停。回放只用于观察，不替玩家执行取水。地图上的水槽、角色携带的水和木料、交付的木板随真实进度变化。保留 v0.1 存档和手记。

新增 `src/demos.js` 管理动作回放。水井与容器细节为程序绘制，人物继续使用原有图集。

## v0.3 · 动作与流程修复

- 倒水改为确定性时间线：提起 → 移动 → 倾斜 → 水流落入 → 水位逐渐上升 → 扶正；桶内剩余量、空中水流和接收量保持一致。
- 示范结束停在最后一帧，不自动清空重播；可暂停、逐动作看、手动重播。
- 观看示范不获得物品；实际取水完成后才提交状态。取消或中途刷新不会凭空获得水。双人帮忙与单人取水有不同画面。
- 修复重复送水再次扣除、重复拿木料和重复改刻印；修复存档中木料已交付却仍携带的矛盾。
- 修复岸边船工被地图清理删掉；水槽与船头补齐碰撞；修正水壶、木料、船等错误贴图。
- 修复空格抢占按钮、弹窗方向键导致人物移动、摇杆残留输入；移动步长不再超过寻路终点。

新增 `src/water.mjs`（可逐帧测试的动作模型）与 `src/objects.js`（语义对应的像素物件绘制）。完整检查记录见源码包 `QA.md`。

## v0.4 · 看得懂的行动进度

- 人物与地点头顶区分 `! 有事可做`、`✓ 此处已完成`、`··· 等待其他事情`。
- 互动面板保留当前完成状态与“下一步”导航，不再只依靠短暂提示。
- “旅途 / 去哪里”列出五件事情的完成情况，并区分取水/送水、拿木料/交付、交付/刻印确认。
- 已完成动作有明确反馈；水槽和水壶装满后相应按钮标记完成并禁用。
- 进度由已有存档的真实行动推导，不把见过对话、看过示范当作完成。旧存档自动显示进度。

## v0.5 · 为触屏重新设计操作

- 浮动模拟摇杆，按落点定位、随拖动距离调速；松手、取消、切换页面均清除输入。
- 人物和物件扩大可点范围；点地面显示落点反馈，拖动或长按不误判为寻路点击。
- 右手按钮直接显示正在做什么：交谈、查看、停下或选择地点。
- 面板增加下拉把手、按压反馈与更大的动作按钮；竖屏使用底部面板，调整镜头和像素缩放，避免遮住交谈人物。
- 保留旧存档、进度提示、键盘和点地寻路。新增 touch.mjs / touch.css 与多指释放、拖动取消测试。
